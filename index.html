VT Birlamchi sozlash kerak

Bu platforma hali hech qaysi Firebase loyihaga ulanmagan. Ishga tushirishdan oldin quyidagilarni bajaring:
  1. Firebase Console'da yangi loyiha yarating.
  2. Build → Firestore Database'ni yoqing (production mode).
  3. Build → Authentication → Sign-in method'da Email/Password'ni yoqing, so'ng Users bo'limida o'zingiz uchun email+parol yaratib qo'ying.
  4. Loyiha sozlamalaridan (⚙️ → Project settings → your apps → Web app) firebaseConfig ni olib, shu faylning boshidagi FIREBASE_CONFIG o'zgaruvchisiga joylashtiring.
  5. ALLOWED_EMAILS ro'yxatiga xodimlar emailini yozing.
  6. firestore.rules faylini Firebase Console → Firestore → Rules bo'limiga joylashtiring (yoki Firebase CLI bilan deploy qiling).
Barchasini bajargach, sahifani qayta yuklang (F5).
